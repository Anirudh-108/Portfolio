Example Canada Payload
----------------------

{
  "contactInfo": {
    "communication": {
      "country": "1",
      "phoneNumber": "5554321",
      "areaCode": "416",
      "number": "5554111", (this is getting updated in DHR)
      "emailAddress": "ca.candidate@gmail.com",
      "phoneType": "H1",
      "fromDate": "2024-01-15",
      "emailType": "H1"
    },
    "currentAddress": {
      "AddressLine1": "100 King St W Lake",
      "TownOrCity": "Toronto",
      "State": "ON",
      "Country": "CA",
      "PostalCode": "M5H2N2",
      "Building": "Tower B",
      "addressType": "HOME", pass "HOME" for Current & "MAIL" for Permanent Address
      "startDate": "2024-01-15"
    }
  }
} 

In "addressType" pass "HOME" for Current Address & "MAIL" for Permanent Address (depends on User's selection)
